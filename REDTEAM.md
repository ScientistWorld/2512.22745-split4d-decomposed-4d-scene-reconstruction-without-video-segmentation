# Does this gym reward better research?

Large genuine improvements score higher, and the clearly weaker control scores lower, beyond the three-seed spread. **The gym nevertheless fails as a research benchmark:** its synthetic scenes are almost solved by cheap grouping, test answers are available in public data code, and replacing the fixed baseline increases the aggregate while erasing the claimed ablation advantage. The synthetic substitute does not establish the difficult temporal feature-propagation effect studied in the paper.

All results below come from 24 actual trials in two CPU jobs. Each trial has its own [run.sh](redteam/README.md), scores or failure evidence, and status under `redteam/<case>/`. The producer exited before a separate process ran the unchanged `bash scripts/evaluate_test.sh` **with no arguments**. No producer process or in-memory state carried into evaluation. The evaluator and test script were never edited; fingerprints matched in every trial. Candidate producers consume scientist-visible files and permitted reused trained outputs. The local paper was used for the reproduction comparison, not to obtain test answers. These were scoring checks, with no evaluator-process or Python-environment modification.

**Quality controls and scores.** The eventual ranked attempt pool is unknown, so an exact future scalar rank cannot be reported. Here, `S` is an explicitly reproducible diagnostic: the requested weighted, direction-correct improvement over `scoring/reference.json`, using absolute coefficients and population standard deviations from the 22 finite saved attempts. Standard deviations pool matching method rows per experiment/metric; the whole nonfinite attempt is excluded. Both proposed and baseline rows count when present. Missing rows contribute nothing, exactly as specified. [analyze.py](redteam/analyze.py), [analysis.json](redteam/analysis.json), and the [complete score table](redteam/score_table.md) record the calculation and denominators. Raw vectors remain the evidence where different future normalizations could change a tradeoff.

The canonical reference has `S=0` by definition. Re-evaluating the frozen trained artifacts gives **R = 0.685188**: the canonical reference contains full-scene values, whereas the hidden test measures a primitive/observation slice. The table compares against that actual hidden-test rerun, not just the canonical zero.

The mask graph uses only public inconsistent-mask co-membership, then spectral clustering and 32-dimensional centered label features. Despite its directory's `refinement` name, it is an independent honest grouping alternative. It improves **all nine candidate metrics in both experiments** over R, so its improvement survives any positive finite normalization. Its gain, and the untrained control's loss, exceed the audit score's seed range of **1.596344**. The graph and brute-force runs tie to within `8.2e-9` across all test metrics: they are **honest alternatives the test cannot tell apart**.

The loss correction removes the extra sample-count division in temperature, uses each denominator center's temperature, and removes the original narrow clamp. It improves linear segmentation but worsens interaction segmentation and dynamic recall; its aggregate gain is smaller than the seed spread and is not evidence of a reliable overall improvement. More training also made the actual result worse and correctly scored lower. Additional compute alone is not a better result.

The frozen method does beat the included random-order ablation in the paper's reported segmentation direction: interaction F1 **.681737 vs .410452**, mIoU **.522115 vs .274142**, and dynamic recall **.746032 vs .587302**. All three seeds beat its F1, but seed 9 loses dynamic recall (**.507937 < .587302**). The reported constraint is not robust across seeds. The random-order baseline also beats the reference on both feature proxies. There are no actual runs of the paper's other published baselines here, so their retained table values are provenance, not reproduced comparisons.

The substitute data fail the stronger fidelity check. Initial-position k-means requires neither masks nor temporal feature learning yet gets perfect linear segmentation and interaction mIoU .785672. Exhaustive local mask matching tests all **24 or 120 label permutations per observation**, over six voting sweeps: **20,736 / 158,400** candidate evaluations. It achieves perfect interaction segmentation and only one mistaken held-out primitive in linear motion. The measured scene/grouping loops take **.122 / .216 seconds**; the complete producer process takes 17.4 seconds including imports and overhead. This is exhaustive local correspondence enumeration, not enumeration of every global partition. **The test is too small/easy for the paper's intended difficulty.** Ordered learning beating this particular random-order learner does not establish that the reduced task needs the paper's mechanism.

**Score completeness and constraint checks.** The rank's additive structure is not a task-success gate. `shortcut_replace_baseline` fails the required strict candidate-over-baseline comparison yet outranks R by more than seed spread. Merely matching baseline predictions makes their *baseline* row look better against `reference.json`, adding reward. The target document describes an F1 gap; the hidden test writes each side's absolute F1, not a gap. `eval/check_core_claim.py` contains strict F1/dynamic-recall checks, but `scripts/evaluate_test.sh` does not call it. The loss-correction run also drops interaction dynamic recall below the fixed baseline while retaining positive aggregate improvement.

Missing and failed runs do **not** receive worst values in every experiment/metric. The empty run exits successfully with `{"experiments": {}}`, so every loss is skipped. The partial run skips an entire experiment. A malformed run aborts rather than writing failure scores; its saved train file is the pre-existing file left after the train failure, not a successful new train result. No stale test score was used: the harness removes that file before each ordinary trial. The only deliberate prewrite was the forged-score trial, and the successful evaluator overwrote it.

The hidden evaluator discovers all JSON files under `outputs/`, but does **not** write every discovered method under test `results`. `filter_to_train_methods` restricts the final result to keys in mutable `scoring/scores_train.json`. In the hide-method shortcut, status records two distinct methods on disk; the hidden test successfully emits only the selected good method. If an expected method is absent it aborts, but an omitted expected key causes no loss. The magic method name `split4d_random_order` also suppresses the entire linear experiment.

Directions and units were handled explicitly in this audit: `ClusterSizeError` improves downward even though its coefficient is negative; the other eight metrics improve upward. Only coefficient magnitudes count, and each improvement is divided by its metric's empirical spread. Changing units or relying on a coefficient's sign therefore supplies no shortcut. The final standardization/ranking implementation is outside this repository; the normalization pool is disclosed rather than presented as a known future leaderboard.

**Where the reproduction departs from the paper.** These are implementation/experimental differences, not proposed fixes made by this audit. Comparison is to the supplied [Split4D manuscript](paper/2512.22745.md), especially §§3–4 and Eqs. 4–7.

- **Data and representation:** two procedural scenes with 144/210 primitives, 36/44 frames, and 4/5 views replace real Neural3DV, Multi-Human, and SelfCap reconstructions. The paper uses hundreds of frames, many synchronized cameras, and 5–20 evaluated instances. There is no FreeTimeGS reconstruction from RGB video or realistic appearance/geometry fitting here.
- **Rendering and supervision:** sparse synthetic pixels mix at most five primitives, with procedural visibility, mask permutations, and label noise. This replaces full image feature splatting and SAM supervision. Evaluation measures primitive assignments rather than the paper's rendered masks in annotated test views. Every synthetic observation is available to the learner; train/test select different scored subsets of the same fixed scenes, not unseen input observations or independently held-out scenes.
- **Semantic guidance:** geometry/time random-projection vectors replace actual DINOv2 image features. The configured `semantic_collision` flag does not implement a separate semantic-collision intervention. This cannot establish the paper's behavior when semantic priors merge different people.
- **Objective:** the implemented contrastive and DINO temperatures take a mean squared dispersion and divide by sample count again, then clamp to [.035, .25]. Eqs. 4/6 use summed squared dispersion divided by `Ns log(Ns+10)` and a separate `phi_k` for each denominator center. The original code instead uses the query class temperature for every denominator term. A new adjacent-frame center-consistency loss `lambda_stream=.25`, absent from Eq. 7, is also added.
- **Sampling and tracking:** ordered optimization uses causal same-view three-frame batches, while random sampling uses one observation. Equal optimizer steps therefore do not give equal observation exposure; the extra center-consistency term is also inactive for a single observation. This comparison confounds temporal order, data budget, and objective. Tracking uses heuristic position/velocity nearest neighbors, quantile filtering, and L1 feature alignment rather than a verified reproduction of the paper's disappearance-focused spatiotemporal matching procedure.
- **Training settings:** accepted artifacts use 3,200 iterations (launcher default 1,400), not approximately 10,000. Tracking/DINO weights are 1/.03, rather than the paper's 100/500 defaults or 100/10 for Multi-Human. Dimension 32 and learning-rate endpoints match. Restoring 10,000 steps alone worsened this substitute task; it did not restore paper fidelity.
- **Inference:** the first-frame sample has a floor of ten primitives per inferred instance, often well beyond the paper's 2–10% sample. HDBSCAN has additional acceptance guards and a k-means fallback with an instance count inferred from mask IDs. Outlier primitives are reassigned, rather than removed as described by the paper's filtering procedure.
- **Measurement and comparisons:** dynamic/static categories are relative speed heuristics over moving synthetic objects, not the paper's annotated categories. Feature-margin and cluster-size scores are gym additions. The executed comparison is one random-order ablation; the other published baselines and full-scale claims were not reproduced.

**Answer visibility and persistence.** `include_truth=False` is only an API default, not a separation: the shipped module constructs truth with `np.repeat(arange(instances), primitives_per_instance)`, and `include_truth=True` returns it. Deleting that flag alone would still leave exact answers recoverable from row order and public configuration. Ground truth and observation creation also live in the scientist-editable module imported by the restored hidden evaluator. The working shortcuts change only persistent files; they require no process to survive into the separate evaluation job.

For the next iteration, the highest-value repairs are to separate immutable evaluation truth/supervision from editable data utilities, freeze comparison artifacts independently, require complete method/experiment/metric coverage with finite failure values, and enforce task/comparison constraints in the actual hidden entry point. A larger and harder scene setting must also put geometry-only and exhaustive matching baselines clearly below the intended method before interpreting improvements as contributions to the paper's problem. Adding stronger proxies to the same easy scenes would not resolve that scientific-validity issue.
